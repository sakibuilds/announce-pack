# Announce Pack

Turn one announcement brief into a press release, outreach pitch, and social post.

- Fill in the news, supporting points, an optional quote, and press contact.
- Live copy blocks: headlines, lede, body, quote, about/boilerplate, journalist pitch, and a social post.
- One-click copy per block or copy-all. Draft auto-saves to localStorage.

Pure client-side, no backend, no data storage.
